# 🚀 Data Science Roadmap & Portfolio

¡Hola! Bienvenido a mi repositorio público. Este espacio documenta mi viaje estructurado desde los fundamentos de la lógica de programación hasta el Análisis de Datos avanzado y Machine Learning. 

Este repositorio no es solo una colección de scripts; es un **Diario de Arquitectura de Datos** donde documento mis procesos lógicos, depuración de errores y resolución de problemas de negocio reales.

## 🧠 Metodología de Estudio
Trabajo bajo reglas estrictas que simulan un entorno profesional real:
- **La Regla del 3x3:** Por cada 3 conceptos técnicos nuevos, desarrollo 3 algoritmos para solidificarlos.
- **Mentalidad QA (Quality Assurance):** Todo el código escrito aquí es testeado modificando datos y buscando "Edge Cases" o fallos (Bugs Fantasmas).
- **Lógica de Negocio Primero:** Antes de escribir una sola línea de Python, todos los problemas se desglosan en **pseudocódigo abstracto** para diseñar el algoritmo.

## 📂 Estructura del Repositorio y Progreso

### 🏗️ Fase 2: Lógica, Cimientos y Pseudocódigo `[Completado]`
- Descomposición de problemas complejos.
- Variables de control, Acumuladores y Contadores matemáticos.
- Algoritmos abstractos (Lógica del "Campeón" para Min/Max).

### 💻 Fase 3: Python Profundo y Algoritmia `[En Progreso]`
Resolución de retos de nivel entrevista técnica (DataLemur/LeetCode) orientados a negocios (Ciberseguridad, Finanzas, E-Commerce, NLP).
- **Listas y Arrays:** Control de flujo avanzado (`break`, `continue`, `For-Else`), índices espaciales, y extracción de datos.
- **Hash Maps (Diccionarios):** Estructura de datos, agrupación dinámica (Lógica *Group By*), actualización y mutación de bases de datos.
- **Formato Universal (JSON):** Manipulación híbrida (Listas que contienen diccionarios), filtros combinados y acceso directo a yugular.
- **Manejo de Errores:** Identificación y resolución de `TypeError`, `ValueError`, `IndexError` y ejecución incondicional (Código Muerto).

- **Fase 4:** Matemáticas (Estadística, Álgebra) y Análisis de Datos (Pandas, Numpy, Visualización).
